# 📊 CodeAlpha Data Analytics – Task 2

## Exploratory Data Analysis (EDA) on Unemployment in India

This project is submitted as **Task 2** for the **CodeAlpha Data Analytics Internship**. The objective is to perform Exploratory Data Analysis (EDA) on the unemployment dataset using Python and visualize meaningful insights.

## 📌 Project Objective

- Clean and preprocess the dataset
- Explore unemployment trends across India
- Analyze regional and monthly unemployment rates
- Create informative visualizations
- Draw data-driven insights

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
